Aspyr has announced the release of a new “Community” update for Tomb Raider 1-3 Remastered. Players on Nintendo Switch 2, Switch, and elsewhere can download it now.

The update includes new, community-requested features as well as bug fixes and optimizations. As part of this, the game now supports 60 FPS in Classic Graphics mode, a brightness slider, and more.

Brightness Slider: Change the brightness of any level across all 3 games (best results with intended use in HD Graphics Mode).

60 FPS in Classic Graphics Mode: Framerate is now 60 fps in Classic for a seamless gameplay experience on any console.

Pickup Highlight: Key items Lara can pick up are now brighter and more visible in HD Graphics Mode.

Fixed a clipping issue in Natla’s Mines where the character could pass through the boat.

Fixed a UI bug where harpoon gun ammo counts were not displayed.

Added missing descriptions for several modifiers in Challenge Mode.

Fixed a physics issue in the Living Quarters where Lara remained hanging in the air.

Fixed a visual rendering issue in Tomb of Tihocan where boulders would flicker in and out of view.

Improved the reliability of executing a running Swan Dive when using touch controls.

Fixed a grab-mechanic issue in The Cistern level for ledges.

Fixed an issue where inverse controller settings were not applied correctly.

Changed the default value for “Retro FPS” to enabled across all applicable platforms.

Improved ladder mounting mechanics in the Opera House level.

Fixed a sequence breaking issue in Atlantis where backflipping with Tank Controls bypassed lighting triggers.

Fixed a bug where the last used Challenge Mode outfit incorrectly persisted in normal levels and Lara’s Home.

Corrected a tooltip error regarding game completion requirements for the Golden Pistols.

Fixed a bug preventing Photo Mode from opening correctly without extra input.

Fixed a collision issue in the City of Khamoon where Lara could fall through a half-opened trapdoor.

Fixed an issue in St. Francis Folly where Lara and lions could become stuck in corners.

Fixed a softlock in Highland Fling caused by Lara getting stuck after jumping onto a rock.

Fixed environmental clipping issues involving the T-Rex upon its defeat.

Fixed a collision bug allowing characters to clip through the Cargo Plane’s cockpit.

Fixed flickering “Goo” textures in Room 3 of the Reunion level while in Classic Mode.

Fixed flickering textures in the Shakespeare Cliff secret area while in Classic Mode.

Fixed missing enemy spawns in the Caves of Kaliya when utilizing type modifiers.

Fixed glitched enemy spawns in Lud’s Gate when using the randomizer.

Fixed an issue in the Crash Site where the airplane cargo door failed to open.

Fixed a softlock where the T-Rex bite failed to trigger a death screen

Tomb Raider 1-3 Remastered can be purchased on Nintendo Switch 2 and Switch. We have more coverage of both systems here and here.
